Cómo utilizar el sistema

  1. En la portada elegí una sola de las cuatro formas de crear el modo.
  2. Si usás Crear un modo, escribí el contexto y presioná VALIDAR Y VER RECOMENDACIONES una sola vez.
  3. Con el texto validado, podés cambiar de área y las recomendaciones se actualizan automáticamente, reiniciando el listado desde arriba. Después seleccioná entre una y cinco capacidades compatibles.
  4. Presioná GENERAR COMANDO.
  5. El comando aparecerá automáticamente en pantalla.
  6. Copialo las veces que necesites y pegalo en la IA externa.

Los cuatro tarjetones son caminos independientes. No hace falta utilizarlos todos.

El comando sólo activa una forma profesional de trabajo. La IA externa debe confirmar el modo y esperar tu primera tarea posterior.

Durante el desarrollo se observó interpretación correcta en distintas IA conversacionales externas. La aplicación no depende de ninguna de ellas ni garantiza un comportamiento idéntico entre proveedores.
